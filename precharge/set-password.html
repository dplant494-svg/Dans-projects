Set the Precharge password

One shared password protects the Precharge Calculator and its request inbox. This page never sends anything anywhere — it just creates a small file called gate-config.js holding a scrambled (hashed) version of your password.

Then:
  1. Save the downloaded gate-config.js into C:\TSC-Dashboard\precharge\ (replace the old one if there is one).
  2. Run Deploy-Dashboard.ps1 — it publishes the file next to the calculator and inbox on the server.
  3. Open the calculator: the login box now asks for the new password. Anyone who had ticked "remember on this computer" will be asked again.
This gate keeps people out of the pages. It cannot stop someone who already knows a direct file URL on the open sandbox share — for that, the folder needs server-side authentication or encrypted files when this goes to production.
