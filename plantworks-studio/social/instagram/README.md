# Instagram launch pack

Nine square posts (1080×1080) in `posts/`, numbered in posting order. `grid-preview.png` shows how the profile grid looks once all nine are up. Sources in `src/` (open an HTML file in a browser at 1080×1080 and screenshot it to regenerate; the two phone-frame posts use `shot-*.png`).

Spanish lines below need a native read before posting, same rule as the site.

## Set-up (once, 30 minutes)

1. Create the account with `info@plantworksstudio.com`. Handle: **plantworksstudio**. If taken, `plantworks.studio`.
2. Switch to a **Professional account → Business**, category "Web designer". This unlocks insights, the WhatsApp button and Meta Business Suite.
3. Profile photo: `site/brand/mark-512.png` (the P mark).
4. Name field: `Plantworks Studio · Web & AI`. The name field is searchable; the handle is not.
5. Bio (150 characters max):
   ```
   Websites for small businesses, engineered not to fail.
   UK & Costa del Sol · remote everywhere
   English & Spanish · fixed prices
   ```
6. Website: `https://plantworksstudio.com`
7. Contact buttons: Email `info@plantworksstudio.com`, WhatsApp `+34 722 676 631`. Location: leave blank.
8. Create a Facebook Page with the same name and link it (Settings → Business tools → Connect). Needed for the WhatsApp button, for scheduling, and for Facebook groups later.
9. Post the nine images over three days, three a day, in order. Instagram shows the newest first, so the grid ends up 09-08-07 on top. That is intended: contact, offer and process are what a visitor sees first.
10. After posting: pin 08 (launch offer), 04 (packages) and 09 (contact). Pinned posts stay at the top of the grid.
11. Story highlights, one each, named `Packages`, `Work`, `How`, `Contact`. Cover: the P mark.
