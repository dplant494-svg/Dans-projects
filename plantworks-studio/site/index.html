Two languages, done properly

Half your customers search in Spanish. Google needs telling which page is which.

A translated page on its own isn't enough. Search engines need a signal called hreflang that pairs every English page with its Spanish twin. Get it wrong and the two versions compete against each other; get it right and each ranks for the people searching in that language.

  • Every page paired English and Spanish versions linked to each other in the code, on every page, with a sensible default for everyone else.
  • Real translation Copy written in Spanish, not run through a plug-in. Paid translated copy is proofread by a native speaker before it goes live.
  • Local search in both languages Business details, hours and services marked up so Google Maps and search results show the right thing in the right language.
  • One site, one domain No separate Spanish site to maintain. Language folders on the domain you already own.
<!-- on every English page --> <link rel="alternate" hreflang="en" href="https://yourbusiness.es/"> <link rel="alternate" hreflang="es" href="https://yourbusiness.es/es/"> <link rel="alternate" hreflang="x-default" href="https://yourbusiness.es/"> <!-- and the mirror of it on every Spanish page -->
