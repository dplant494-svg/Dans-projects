The ten steps in words

  1. Eric issues from the Bulletin Board: SFI codes, rigs, due date, PDFs, photographs. Save JSON always works; Post sends it.
  2. The post lands in PostedReports as one file per revision. It is never edited afterwards.
  3. The flow emails each applicable rig its contacts from the Rigs sheet, PDFs attached, link to the AAB on the dashboard, Eric and the office in copy.
  4. The scanner records the AAB, groups revisions by number, and writes the data file the rig page reads and the dashboard tab shows.
  5. The rig acknowledges on the sacred page: the TSL of each crew, name and crew, date (DIR-37-0161 §2.2.4: both TSLs for a Priority 3). Where the advisory asks for an action, the rig closes it later with a comment and evidence photographs.
  6. The acknowledgement posts as its own file through the same trigger.
  7. The flow tells Eric and the office that the rig has acknowledged.
  8. The scanner joins acknowledgements to AABs and computes each rig's status.
  9. The dashboard shows it: overdue count first, then percent acknowledged, then the detail.
  10. Overdue is chased daily until the acknowledgement arrives.
